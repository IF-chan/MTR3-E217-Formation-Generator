# MTR3 E217编组及资源包生成器 / MTR3 E217 Formation & Resource-Pack Generator
中文 | [English](#english)

## 中文
基于[[MTR3] JR东日本 E217系](https://modrinth.com/resourcepack/e217-series-train-mtr3)资源包制作的列车编组及资源包生成器，能够自由生成你想要的编组。

直接下载源代码，然后双击 `build_pack.bat`，可直接选择预设编组，也可以自定义编组，生成的资源包在 `output` 文件夹下。

如果你在使用资源包本体或编组生成器的时候遇到任何问题都可以在[Issues](https://github.com/IF-chan/MTR3-E217-Formation-Generator/issues)里提出。

## English
Formation & Resource Pack Generator based on [[MTR3] JR東日本 E217系 | JR East E235 series](https://modrinth.com/resourcepack/e217-series-train-mtr3)

You can generate any formation you want freely.

Download the source code and click `build_pack.bat`. You can directly use preset formation or generate a custom formation. Check the custom resource pack in `output` folder.

If you have problem when using resource pack or Formation & Resource Pack Generator, you can create a new issue.
